# موقع م. أسامة معين بوادي (CV)

موقع شخصي بالعربي والإنجليزي: خلفية غامقة، أيقونات زجاجية عائمة 3D (Three.js)، وظهور ناعم للعناصر أثناء النزول.

**الرابط بعد النشر:** https://onlinejob114111607.github.io/online-job/osama/

## ⚙️ التعديل
| الملف | شو فيه |
|---|---|
| `src/config.js` | الإيميل، **رقم الواتساب**، روابط السوشال، روابط المشاريع. أي حقل فاضي ما بيظهر. |
| `src/i18n.js` | كل نصوص الموقع بالعربي والإنجليزي. |
| `public/osama.webp` | الصورة الشخصية (بدون خلفية). |
| `public/p-*.webp` | صور المشاريع. |

## مميزات
- زر **EN / ع** لتبديل اللغة (بيتذكّر الاختيار). رابط مباشر: `?lang=en`
- زر **تحميل السيرة الذاتية** بيطبع نسخة CV نظيفة (صفحة A4) أو بيحفظها PDF.
- على الأجهزة الضعيفة بيخفّف المشهد لحاله، ومع «تقليل الحركة» بيوقف الأنيميشن.
- للتجربة بدون 3D: `?nogl`

## التشغيل
```
cd osama-cv
npm install
npm run dev
npm run build   # ← dist/
```
أي تعديل بمجلد `osama-cv/` بيوصل لفرع `main` ← GitHub Actions بيبنيه وبيحطه بمجلد `osama/`.
