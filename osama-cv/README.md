# موقع م. أسامة معين بوادي (CV)

موقع شخصي، الإنجليزية أساسية مع ترجمة عربية فصحى: غامق مع أبيض متوهج، شاشة افتتاحية، كلمات كبيرة مثبّتة أثناء النزول، شهادات مهارات، ونوافذ تفاصيل للمشاريع.

**الرابط بعد النشر:** https://onlinejob114111607.github.io/online-job/osama/

## ⚙️ التعديل
| الملف | شو فيه |
|---|---|
| `src/config.js` | الإيميل، **رقم الواتساب**، روابط السوشال، روابط المشاريع. أي حقل فاضي ما بيظهر. |
| `src/i18n.js` | كل نصوص الموقع (إنجليزي + عربي فصحى)، والمهارات، والشهادات. |
| `public/osama.webp` | الصورة الشخصية. |
| `public/p-*.webp` | صور المشاريع. |

## مميزات
- زر **عربي / EN** لتبديل اللغة (بيتذكّر الاختيار). رابط مباشر بالعربي: `?lang=ar`
- زر **تحميل السيرة الذاتية** بيطبع نسخة CV نظيفة (صفحة A4) أو بيحفظها PDF.
- مع إعداد «تقليل الحركة» بالجهاز بيوقف الأنيميشن.

## التشغيل
```
cd osama-cv
npm install
npm run dev
npm run build   # ← dist/
```
أي تعديل بمجلد `osama-cv/` بيوصل لفرع `main` ← GitHub Actions بيبنيه وبيحطه بمجلد `osama/`.
