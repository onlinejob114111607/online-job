# عامل متابعة المودل 🎓

بيتابع مودل الطلاب بكل الجامعات، وبيبعتلك تنبيه على تيليجرام لما:
- ينزل **واجب / اختبار / مشروع / نشاط / ملف جديد**
- **يتغيّر موعد** تسليم
- يقرب الموعد: **قبل 3 أيام، وقبل يوم، وقبل 3 ساعات** (إذا لسا ما انسلّم وما علّمته "خلصت")
- كل يوم الصبح: **ملخص** بكل المستحق خلال أسبوع
- الربط يخرب (الطالب غيّر كلمة السر مثلاً)

الإدارة من لوحة التحكم ← **متابعة المودل**.

## التشغيل على Termux
```
pkg install nodejs git
git clone https://github.com/onlinejob114111607/online-job
cd online-job/moodle-worker
npm install
cp .env.example .env
nano .env        # عبّي القيم (شوف تحت)
termux-wake-lock # عشان الجوال ما يوقفه
npm start
```
للتحديث بعدين: `git pull && npm install` ثم شغّله من جديد.

## ملف ‎.env
| المتغير | شو هو |
|---|---|
| `SUPABASE_URL` | رابط مشروع Supabase |
| `SUPABASE_KEY` | مفتاح `service_role`، **أو** المفتاح العام مع `ADMIN_EMAIL` و `ADMIN_PASSWORD` لحساب الأدمن (نفس اللي بتعمله العمّال التانيين) |
| `TG_BOT_TOKEN` | توكن البوت من ‎@BotFather |
| `TG_CHAT_ID` | رقم المحادثة اللي بتوصلها التنبيهات (ابعت رسالة للبوت، وافتح `https://api.telegram.org/bot<التوكن>/getUpdates` وخد `chat.id`) |
| `SYNC_MINUTES` | كل قديش دقيقة بيفحص (الافتراضي 60، أقل إشي 15) |
| `DIGEST_HOUR` | ساعة ملخص الصبح (الافتراضي 8) |
| `TIMEZONE` | المنطقة الزمنية (الافتراضي `Asia/Gaza`) |

## طريقتين للربط
1. **الرقم الجامعي + كلمة السر**: بيعطي كل إشي (المواد، الملفات الجديدة، الواجبات، الاختبارات، هل الطالب سلّم، العلامة). كلمة السر بتنستعمل **مرة وحدة** لأخذ مفتاح دخول (نفس تطبيق Moodle على الموبايل)، وما بتنحفظ.
2. **رابط التقويم**: للجامعات اللي دخولها عن طريق Microsoft أو Google. بيعطي المواعيد بس. الطالب بيجيبه من: التقويم ← استيراد أو تصدير التقويمات ← تصدير التقويم ← "كل الأحداث" و"الأيام الأخيرة والقادمة" ← الحصول على رابط التقويم.

زر **«افحص الموقع»** باللوحة بيقلّك أي طريقة بتزبط مع الجامعة.

## الأمان
- اللوحة بتشفّر كلمة السر بالمفتاح العام للعامل قبل ما تطلع من المتصفح، والعامل بس بيقدر يفكها.
- مفتاح العامل الخاص (`data/key.pem`) ومفاتيح دخول الطلاب (`data/secrets.json`) **على الجوال بس**. لا ترفعهم ولا تشاركهم.
- إذا ضاع الجوال أو انمسح مجلد `data/`: شغّل العامل من جديد، واعمل «إعادة ربط» لكل طالب.

## البيانات بقاعدة البيانات (جدول docs)
- `moodle_students` — الطلاب وحالة الربط
- `moodle_items` — كل نشاط/واجب/اختبار مع موعده وحالته
- `workers/moodle` — حالة العامل ومفتاحه العام
- `commands` (worker = `moodle`) — أوامر اللوحة
