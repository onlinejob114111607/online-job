# صفحة هبوط جودي ستور – Joudi Store

صفحة هبوط فاخرة ثلاثية الأبعاد (React + Vite + Tailwind + React Three Fiber + GSAP/ScrollTrigger + Lenis + Framer Motion).

**الرابط بعد النشر:** https://onlinejob114111607.github.io/online-job/joudi/

## ⚙️ قبل النشر — عدّلي ملف واحد: `src/config.js`
| الإعداد | شو بيعمل |
|---|---|
| `WHATSAPP_NUMBER` | رقم واتساب بصيغة دولية بدون + (مثال `970599123456`). **طول ما هو فاضي، أزرار واتساب بتودّي على المتجر.** |
| `SOCIAL.facebook` / `SOCIAL.instagram` | روابط الصفحات (فاضي = الزر بيودّي على المتجر). |
| `CATEGORY_LINKS` | رابط كل تشكيلة بالمتجر (حالياً كلها على الصفحة الرئيسية للمتجر). |
| `TESTIMONIALS` | آراء العميلات **الحقيقية فقط**. البطاقة الفاضية بتظهر «[رأي عميلة حقيقي]». |

## التشغيل
```
cd joudi-landing
npm install
npm run dev       # تشغيل محلي
npm run build     # بناء ← dist/
```
أي تعديل بمجلد `joudi-landing/` بيوصل لفرع `main` ← GitHub Actions بيبنيه وبيحطه بمجلد `joudi/` بجذر الريبو (الملف `.github/workflows/deploy-joudi.yml`).

## الصور
- `public/images/*.webp` — صور التشكيلات + صورة الهيرو البديلة (للأجهزة بدون WebGL). هاي صور 3D مولّدة كمكان مؤقت؛ **الأفضل تستبدليها بصور منتجات حقيقية** بنفس الاسم (WebP، نسبة 4:5، عرض ~1000px).
- `public/og.jpg` — صورة المشاركة على فيسبوك/واتساب (1200×630).
- لإعادة توليدها: `npm run stills` (بيحتاج Playwright + Chromium).

## بنية الكود
```
src/
  config.js            إعدادات المتجر (واتساب، روابط، آراء)
  lib/                 كشف الجهاز ومستوى الجودة، التمرير الناعم، الحالة المشتركة
  components/          Preloader، المؤشر الذهبي، أزرار مغناطيسية، SplitText، Reveal، صورة بتشويه سائل
  sections/            أقسام الصفحة بالترتيب
  three/               المشاهد ثلاثية الأبعاد + shaders (حرير، غبار ذهبي، رخام، ذهب)
  stills/              صفحة داخلية لتوليد الصور (مش منشورة)
```

## الأداء وإمكانية الوصول
- مستوى الجودة بيتحدد تلقائياً (`high` / `mid` / `low`) حسب الجهاز، وبينزل لحاله إذا هبط الـ fps (عدد الجزيئات، الدقة، bloom، زجاج transmission).
- بدون WebGL: صورة ثابتة للهيرو، أيقونات SVG، وأرقام بتدرّج ذهبي.
- `prefers-reduced-motion`: بدون تمرير ناعم ولا pin ولا حركات طويلة؛ المعرض الأفقي بيصير سحب عادي.
- المشاهد بتوقف رسم لما تطلع من الشاشة.
- الموديلات مبنية بالكود (procedural) فما في ملفات GLB للتحميل أصلاً. إذا بدك تضيفي موديل حقيقي: ضغطيه بـ `gltf-transform draco` وحمّليه بـ `useGLTF(url, true)` من drei.
- للتجربة: `?tier=low` أو `?tier=high` أو `?nogl` بآخر الرابط.
